# 解剖 · 物理 · 词汇表

写情绪特写时按区取材。原则：**名词精确到解剖，动词精确到方向和幅度**。

## 面部肌肉/部位速查（按区）

| 区 | 部位/肌肉 | 能表达什么 |
|----|-----------|-----------|
| 眉 | 皱眉肌、眉间纹（川字） | 用力忍、愤怒、后悔 |
| 眉 | 眉毛内端下沉 | 哀戚（肌肉放弃用力后的自然垂落） |
| 眉 | 八字眉（眉心上挑+眉间皱） | 悲伤求助；喜极而泣的标志 |
| 眼 | 眼轮匝肌收缩、眯眼 | 强忍、用力看、笑 |
| 眼 | 下眼睑 | 泪水线积聚处（泪水第一站） |
| 眼 | 眨眼频率 | 密集=压制；停止驱散=放弃抵抗；一次不受控的眨眼=溢出扳机 |
| 眼 | 睫毛 | 湿润粘连（哭的尾段质感） |
| 眼 | 焦距/视线 | 涣散=空洞；快速瞟=恐惧；重新有焦距=释然 |
| 鼻 | 鼻翼扩张 | 呼吸用力、愤怒 |
| 鼻 | 鼻翼细碎颤动 | 哭的前兆（第 6 阶段信号） |
| 嘴 | 抿唇 | 压制的总开关（几乎所有情绪通用） |
| 嘴 | 嘴角下压 / 一边上提 / 颤着上扬 | 悲伤 / 自嘲·冷笑 / 喜极 |
| 嘴 | 嘴唇分开一缝又合拢 | 欲言又止（未完成的动作） |
| 嘴 | 下唇细碎颤抖→咬住→再颤 | 失守前兆的标准振荡 |
| 嘴 | 下唇外翻、嘴微张 | 哭出声的前一帧 |
| 颌/喉 | 咬肌鼓起、下颌线绷紧 | 咬牙、愤怒、强压声音 |
| 颌/喉 | 喉结滚动、吞咽 | 紧张、强忍（通用生理信号） |
| 颌/喉 | 喉咙哽住 | 声音失守前 |
| 肩/头 | 肩膀细碎不规律颤动 | 哭（明写「不是整齐的抽泣」） |
| 肩/头 | 肩膀极轻耸动被止住 / 松下来 | 忍笑 / 释然 |
| 头 | 微低→平视→仰→低垂 | 头的位置 = 弧线进度条 |

## 泪水物理链

1. **积聚**：下眼睑泪水线隐约积聚（第一阶段就该埋）
2. **压制**：密集眨眼 / 仰头借重力逼回
3. **临界**：眼角泛红、泪水在眼角聚拢
4. **溢出扳机**：一次不受控的眨眼把泪「挤」出来——泪永远是眨眼触发的，不是自己流的
5. **路径随头位**：仰头位→眼尾→鬓角/耳侧；直立位→脸颊→下颌线→滴落
6. **形态演进**：细线 → 持续流淌 → 全面漫开（分阶段递进，别一步到位）
7. **可见性条件**：侧光/逆光下泪痕反光；顺光里泪几乎看不见
8. **防翻车词**：「物理自然，不悬挂」；左右眼不同时（右眼先，左眼稍晚）

## 呼吸递进（情绪的节拍器）

极浅（压制）→ 刻意放缓（装镇定）→ 分段吸气（碎裂前）→ 无法控制的深吸气（带鼻腔湿润声）→ 气流在喉咙哽住 → 颤抖呼气 → 呼吸彻底碎裂

## 声音词汇（有声视频模型必写）

克制的吞咽声 / 鼻腔湿润声 / 气流哽住 / 咬牙强压 / 第一声（低沉、沙哑、破碎，从喉咙深处挤出）/ 哽咽 / 不自觉的吸鼻声 / 声音在第二个字劈了 / 闷闷的哭或笑（捂着嘴时）

## 幅度副词阶梯（强度递增 = 情绪递进）

极轻微 < 微微 < 轻轻 < 缓缓 < 渐渐 < 密集 / 细碎 < 不受控制 < 彻底

- 全片副词强度应随阶段爬坡；特写镜头**永远不写「剧烈」**
- 每个动作都必须带一个副词——没副词的动作，模型会按最大幅度演

## 镜头 · 灯光 · 色调

- **画面稳定**：特写禁运镜，任何推拉摇移都稀释表演
- **侧光**：面部立体 + 泪痕反光（写清打亮哪侧脸）
- 冷蓝灰 = 悲伤/压抑；暖金/逆光 = 释然/喜极；硬光高对比 = 愤怒/恐惧；由冷转暖 = 释然弧线的叙事手段
- 轻微胶片颗粒 = 皮肤肌理真实感；背景简洁 = 注意力全在脸上

## 防崩三件套

1. **解剖词锚定**（眼轮匝肌/眉间纹/咬肌——模型有明确物理目标就不乱扭）
2. **幅度词限幅**（全部动作限定在微表情区间）
3. **尾巴明写**「面部结构不扭曲变形」

另两条纪律：每阶段动作 ≤ 4 个（塞多了模型取舍时会丢戏）；阶段内动作用「先…随后…」写清时序。
