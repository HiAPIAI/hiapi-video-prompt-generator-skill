# 情绪配方库

每条配方给：核心情绪对 / 压抑动机 / 六阶段逐段要点 / 收尾 / 建议光色。套用时**阶段结构不动，只换词汇与失守通道**。

新情绪没有现成配方时，按这个顺序推：定情绪对 → 找压制肌群 → 设计裂缝的混合组合 → 想一个有物理动机的自救动作 → 定失守通道（泪/笑/吼/颤/声音劈了） → 定收尾状态。

## 1. 悲伤 · 克制哭戏（基准范例 · 全文逐句标注）

> 这条是整套方法的来源。读标注 = 读方法。

**【第一阶段：失落与消化】**

> 男主角微微低头，下颌轻收，神情空洞，嘴唇无力合拢，目光直视镜头却焦距涣散，偶尔极轻微地点头，像在无声说服自己接受某件不愿承认的事。喉咙轻轻滚动，完成一次克制的吞咽，嘴唇微微分开一缝，像有话到了嗓子眼却说不出口，停顿后缓缓合拢，什么都没说出来。

标注：
- 「微微低头，下颌轻收」——**身体先行**，情绪没到脸，先到体态。
- 「目光直视镜头却焦距涣散」——矛盾指令造空洞感（在看，但没看见）。
- 「极轻微点头，像在无声说服自己」——**比喻句给内心戏**，不出现「悲伤」二字。
- 「克制的吞咽」——生理细节，紧张/强忍的通用信号。
- 「嘴唇分开一缝→合拢，什么都没说」——**未完成的动作**比任何表情都丧。
- 全段 0 个情绪词，全是可渲染的物理事件。

**【第二阶段：压制情绪】**

> 嘴唇重新用力抿紧，眉头轻皱。眼轮匝肌轻轻收缩，双眼微微眯起，眉间纹加深，嘴角向下压，整张脸开始绷紧，悲伤被封死在皮肤之下，呼吸变得极浅。下眼睑泪水线隐约开始积聚，他密集眨眼试图压制，眼角已隐隐泛红。

标注：
- 肌群总动员清单：抿唇 / 皱眉 / **眼轮匝肌**（点名解剖词）/ 眉间纹 / 嘴角下压——每块肌肉一个短句。
- 「悲伤被封死在皮肤之下」——阶段定性句，情绪词只允许出现在这种标签位。
- 「呼吸变得极浅」——呼吸是情绪的节拍器，每阶段都要交代。
- 「泪水线积聚→密集眨眼压制→眼角泛红」——**第一波泄漏被压回**，给后面的崩溃蓄水。

**【第三阶段：苦涩的释怀微表情——悲伤与释然同时存在】**

> 沉默中，他极轻微地点了一下头，幅度极小，像是在心里默默确认了某件事，认了。随后脸上出现一个极其复杂而短暂的微表情——眉头依然轻轻皱着，带着悲伤与后悔，但嘴角却极其细微地向上提拉了一点，不是真正的笑，是那种哭不出来又笑不出来的临界状态，像是释怀，像是自嘲，像是对某段往事最后一次温柔的承认。抿着嘴，嘴角却微微上扬，眉心却依然拧着——这张脸在同一秒里同时承载着两种相反的情绪，真实而令人心碎。这个表情只持续两三秒，转瞬即逝。随后他像是意识到了什么，试图收敛这个表情，嘴角重新被抿平，眉头再次轻轻皱紧，表情回归克制，像是不愿让任何人看见刚才那一刻的自己。

标注：
- 先给心理节点（点头=认了），再给表情——**表情是心理的结果**。
- 混合表情配方 = A 情绪的部位 + B 情绪的部位：眉头皱着（悲伤）+ 嘴角上扬（释然），明写「不是真正的笑」「临界状态」防止模型笑过头。
- 三个「像是」排比给意图，依然不用裸情绪词。
- 「只持续两三秒，转瞬即逝」——**给时长**，模型才知道这是个微表情不是状态。
- 「意识到→主动收敛→回归克制」——**裂缝必须被关上**，后面的崩溃才有分量。这是全片最贵的一拍。

**【第四阶段：仰头——试图稳住，却反而触发崩溃】**

> 他缓缓仰起头，不是为了看向任何地方，而是本能地试图借助重力将积聚的泪意逼回眼眶，下颌朝上，嘴唇微微抵住，喉结轻轻滚动，眼睛微微眯起。仰头的这几秒，表情短暂出现一种强撑的平静，像是以为这个动作能救他。但没有。泪水在仰起的角度下无处可退，在眼角缓慢聚拢，随着一次无法控制的细微眨眼，右眼眼角泪水顺着重力沿眼尾向鬓角方向缓缓溢出，物理自然，不悬挂。左眼稍晚，同样在下一次眨眼后溢出，向耳侧延伸。

标注：
- 仰头给的是**物理动机**（借重力逼回泪水），不是情绪动机——动作有物理原因，模型才不会乱演。
- 「短暂强撑的平静，像是以为这个动作能救他。但没有。」——先给希望再掐灭，节奏上的二次跌落。
- 失守因果链写死：仰起角度→无处可退→**一次不受控的眨眼触发**→右眼先溢→路径精确到「眼尾→鬓角」。
- 「物理自然，不悬挂」——直接针对视频模型泪水贴脸不落的经典翻车。
- 「左眼稍晚」——**对称破缺**，真人感来源。

**【第五阶段：低头——悲伤缓慢溢出，克制但已无法封堵】**

> 他缓缓将头低回正面，重新面对镜头。两道泪痕已在脸上，侧光下清晰反光。他微微抿住嘴唇，嘴角轻轻向下收，眉毛内端轻轻向下沉，是肌肉放弃用力后自然垂落的哀戚弧度。眼睛没有再试图眨动驱散，只是静静涩涩地直视前方。泪水沿脸颊缓缓向下流淌，细而安静。悲伤是克制的，内敛的，藏不住却不想被看见。

标注：
- 「重新面对镜头」——把泪痕展示给观众，表演的管理意识。
- 「侧光下清晰反光」——**泪水的可见性条件**，和技术尾巴的侧光互为伏笔。
- 「眉毛内端下沉 = 肌肉放弃用力后自然垂落」——**放弃也是一个动作**，而且给了力学解释。
- 「没有再试图眨动驱散」——抵抗结束的标志，用「不做某事」来写。
- 「细而安静」——溢出阶段幅度仍然收着，留给第 6 段递进空间。

**【第六阶段：情绪循序渐进爆发】**

> 嘴角抵住的力道开始松动，下唇出现轻微的、不受控制的细碎颤抖，被他咬住，松开，再颤，已经压不回去了。眉间不再是克制的绷紧，而是深深地、疲惫地向下折叠，鼻翼开始以细碎的频率轻轻颤动。泪水漫开，沿脸颊持续流淌，他不再去抵抗。随后是一次无法控制的深吸气——带着清晰的鼻腔湿润声，气流在喉咙深处轻微哽住，他用咬紧牙关强行压下，但已经晚了。嘴角彻底下坠，下唇向外轻轻翻开，嘴微微张开，第一声从喉咙深处挤出——低沉、沙哑、破碎，像被压迫太久的气流从狭窄处强行穿过，是这段情绪里第一个他没有主动发出却无法阻止的声音。这声音一出，所有剩余的克制在一秒内瓦解。肩膀开始不规律地细碎颤动，不是整齐的抽泣，是那种身体已经在哭而本人还在微弱抵抗时产生的细碎震颤。呼吸彻底碎裂，变为急促的分段吸气与颤抖的呼气，夹带细微的哽咽与不自觉的吸鼻声。泪水不再是细线，在脸颊上全面漫开。他的眼睑轻轻合拢，睫毛湿润，头彻底低垂，肩膀持续颤动，整个人安静而完整地哭着——没有戏剧感，没有表演感，只有一个人真正承受某种东西时，身体给出的最诚实的回应。

标注：
- 失守顺序写死：嘴角力道松动→下唇颤→**咬住→松开→再颤**（抵抗-失守的振荡），「已经压不回去了」给不可逆点。
- 眉间从「克制的绷紧」变「疲惫地向下折叠」——同一部位，**性质变化**而不是幅度加大。
- 声音设计：深吸气（鼻腔湿润声）→喉咙哽住→咬牙强压→「已经晚了」→第一声「低沉沙哑破碎」「从狭窄处强行穿过」——给有声视频模型精确的声音事件。
- 「第一个他没有主动发出却无法阻止的声音」——**身体接管意志**的明写。
- 「这声音一出，剩余克制一秒瓦解」——声音是崩溃的扳机，因果明确。
- 「肩膀不规律细碎颤动，不是整齐的抽泣」——用否定句排除表演感抽泣。
- 收尾定调：「没有戏剧感，没有表演感……身体给出的最诚实的回应」——**反表演指令压在结尾**，离生成注意力最近的位置。

**技术尾巴标注**

> 超写实风格，轻微胶片颗粒，冷蓝灰色调，自然漫射侧光灯打亮右脸，背景简洁，画面稳定，4K高清，面部结构不扭曲变形。

- 顺序：风格→颗粒（皮肤肌理真实感）→色调（冷蓝灰=情绪定调）→灯光+**明确方向**（侧光=泪痕反光的伏笔）→背景（排除干扰）→镜头（特写禁运镜）→画质→**防崩指令**（面部结构不扭曲变形）。

## 2. 强忍笑意 → 憋不住

- 情绪对：笑意 × 场合不允许（葬礼/会议/挨训时听到荒诞的事）
- 压制肌群：抿唇（向上顶住的抿）、咬口腔内侧、低头假装做事、肩膀极轻耸动被止住
- 裂缝：一声极轻的鼻息漏气 + 嘴角失控上提半秒，立刻用咳嗽掩盖
- 自救失败：深呼吸 / 喝水 / 转身，气流反而冲破——第一声笑从鼻腔挤出
- 溢出：肩膀持续抖、眼角笑出泪、仍在压声音
- 接管：放弃，脸埋进手或臂弯，笑声闷闷的；抬头时眼角泪光 + 残余笑意 + 一丝歉意
- 光色：中性偏暖，柔光

## 3. 愤怒 · 越压越冷（或爆发）

- 情绪对：愤怒 × 理智/场合（不能在当下发作）
- 承接：听到那句话，手上动作停住，眼神定住（**先静，不是先动**）
- 压制肌群：咬肌鼓起、下颌线绷紧、鼻孔扩张、呼吸变重变慢、手指收拢；眼眶微红（愤怒也有泪）
- 裂缝：一声极轻的嗤笑从鼻腔出来，嘴角一边提起，眼神却更冷（笑和冷同脸）
- 自救失败：转身/深呼吸想压下，对方再补一句→压不住
- 接管（二选一）：
  - **冷爆发（更吓人）**：声音突然压低、咬字极清、语速放慢，只有下巴和手在抖——强度做减法
  - **热爆发**：音量起来但句子短，呼吸粗，眼眶红着不掉泪
- 光色：硬光、高对比、阴影重

## 4. 喜极而泣（等了很久的消息终于来了）

- 情绪对：狂喜 × 不敢信
- 承接：愣住，眼睛微睁，呼吸停半拍，嘴唇微张
- 确认（替代压制段）：极轻地摇头（不是否定，是不敢信），眼眶秒红，泪水线快速积聚
- 裂缝（喜极而泣的标志组合）：嘴角颤着上扬，眉毛却是悲伤的八字——**笑和哭同时在脸**
- 失守：第一滴泪随着一次点头掉下来，笑出声，声音是破的
- 接管：又笑又哭，抬手捂住嘴，肩膀耸动，泪水从指缝下来
- 收尾：放下手，满脸泪痕但笑开了，眼睛是亮的
- 光色：暖金、逆光

## 5. 恐惧 · 强装镇定

- 情绪对：恐惧 × 不能露怯
- 承接：瞳孔微收，**身体先于表情僵住**
- 压制肌群：喉结滚动吞咽、呼吸刻意放缓但胸口起伏变大、眨眼频率升高被强压
- 裂缝：视线不受控地快速瞟向威胁源又拉回来
- 自救失败：伸手去拿东西（杯子/笔）→手在抖，东西碰出声响——**用道具暴露**
- 溢出：呼吸声变粗、鼻翼扩张、额角汗光
- 接管（二选一）：panic 崩溃 / 强行冻结成极度克制的低语
- 光色：冷硬，单侧光，半张脸进阴影

## 6. 委屈 · 被温柔击穿（短剧高频）

- 情绪对：委屈 × 强撑；扳机 = 一句温柔的话——**本来撑得住，被理解反而破防**
- 承接：本来正常说着话，听到那句，话音停了
- 压制：眨眼变快、扯出一个「没事」的笑、轻轻摇头
- 裂缝：笑还挂在脸上，眼眶已经红了——笑和泪同脸
- 自救失败：开口想说「真的没事」，**声音在第二个字就劈了**
- 接管：眼泪掉得又快又安静；被人抱住时才有第一声
- 光色：柔光暖调

## 7. 释然 · 放下（短弧线，3-4 段即可）

- 情绪对：疲惫 × 解脱
- 承接：长久紧绷的肩膀第一次松下来
- 过程：一次真正深长的呼气（整个躯干随之下沉）、闭眼两三秒
- 裂缝：极淡的笑意从嘴角开始，眼睛还红着
- 收尾：睁开眼，眼神从涣散重新有了焦距，看向窗外/远处
- 光色：由冷转暖（光色本身参与叙事）
