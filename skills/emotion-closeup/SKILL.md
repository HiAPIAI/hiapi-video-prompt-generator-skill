# emotion-closeup-prompt

把「一个人真实地哭/笑/破防」写成视频模型能演的 prompt。方法论从一条实跑过的六阶段哭戏 prompt 抽丝剥茧而来（全文+逐句标注见 `references/emotion-library.md`）。

## 一句话原理

**视频模型不会演「情绪」，只会演「带时间顺序的物理事件」。** 所以不写「他很悲伤」，写「哪块肌肉、往哪动、多大幅度、持续几秒、接下来哪块肌肉接管」。真实感不来自强度，来自**抵抗**——崩溃的质量取决于前面压制的质量。

## 核心公式

```
情绪特写 prompt = 六阶段弧线（含反复）
              × 每段「心理标签 + 肌肉动作 + 幅度副词」
              + 泪水/呼吸/声音物理因果链
              + 一处混合情绪裂缝
              + 反表演指令
              + 技术尾巴（风格/色调/灯光/防崩）
```

## 六阶段情绪弧线（骨架）

| # | 阶段 | 职责 | 写法要点 |
|---|------|------|---------|
| 1 | 承接/消化 | 事件落定，人还没反应过来 | 空洞、焦距涣散、极轻点头（像在无声说服自己）、克制的吞咽、欲言又止（嘴唇分开一缝→合拢，什么都没说） |
| 2 | 压制 | 肌肉总动员顶住第一波 | 抿唇、皱眉、眼轮匝肌收缩眯眼、眉间纹加深、嘴角下压、呼吸变浅；第一波生理泄漏被强行压回（泪水线积聚→密集眨眼→眼角泛红） |
| 3 | 裂缝 | 2-3 秒的混合微表情 | 两种相反情绪同时在脸（眉头皱着 + 嘴角极轻上扬），转瞬即逝，被本人察觉后**主动收敛**回克制 |
| 4 | 自救失败 | 有物理动机的动作反而触发失守 | 仰头借重力逼回泪水→短暂强撑的平静→泪水无处可退→一次不受控的眨眼→第一滴泪溢出（右眼先，左眼稍晚） |
| 5 | 溢出 | 放弃封堵，安静地流 | 泪痕在侧光下反光、不再眨眼驱散、眉毛内端放弃用力自然垂落、细而安静 |
| 6 | 接管 | 身体越过意志，完整释放 | 下唇细碎颤抖→咬住→再颤；呼吸碎裂成分段吸气+颤抖呼气；第一个不由自主的声音（低沉沙哑破碎）；肩膀细碎不规律颤动；全程无戏剧感 |

**节奏铁律：**
- 压制（阶段 2-4）篇幅 ≥ 释放（阶段 5-6）；裂缝必须先于崩溃
- 失守必须有物理因果（重力/眨眼/呼吸触发），不允许「突然哭了」
- 阶段结构可复用到任何情绪：结构不动，只换词汇和失守通道（泪→笑→吼→颤→声音劈了）

## 五条真实感原则（为什么这么写有效）

1. **肌肉命名代替情绪词。** 写「眼轮匝肌轻轻收缩、眉间纹加深」，不写「悲伤欲绝」。抽象情绪词是面部扭曲崩坏的第一来源；解剖词给模型确定的物理目标。
2. **每个动作都带幅度副词。** 极轻微 / 微微 / 轻轻 / 缓缓 / 密集 / 细碎 / 彻底——特写镜头的真实感全靠幅度控制，且副词强度随阶段递增 = 情绪递进。特写永远不写「剧烈」。
3. **给情绪一个物理对手。** 仰头逼泪（重力）、眨眼把泪「挤」出来、侧光让泪痕反光——物理因果链给模型确定性事件去渲染，而不是让它猜「悲伤长什么样」。
4. **对称破缺。** 右眼先流泪、左眼稍晚；肩膀颤动「不整齐」。对称 = 渲染感，不对称 = 真人。
5. **身体与意志的 Gap。** 「身体已经在哭而本人还在微弱抵抗」「意识到后试图收敛那个表情」——真实感全在这个 Gap 里；比喻句（「像有话到了嗓子眼」）负责给表演意图，情绪词负责删。

## 工作流

1. **定情绪对和场景**：核心情绪 × 对立情绪（悲伤×释然、狂喜×不敢信、愤怒×理智）；触发事件；**压抑动机**（为什么必须忍——它决定阶段 2-4 的形态）。
2. **套六阶段骨架**：每阶段填——双段式标签（【第N阶段：情绪+动作】，给 what 也给 why）+ 2-4 个肌肉级动作（带幅度副词和先后时序）。时长不够砍成三阶段压缩版：压制→裂缝→溢出。
3. **从词汇表取材**：肌肉/泪水/呼吸/声音/幅度副词查 `references/anatomy-physics.md`；七种情绪的现成配方查 `references/emotion-library.md`。
4. **写技术尾巴**：`[风格]，[颗粒质感]，[色调]，[灯光+方向]，背景简洁，画面稳定，[画质]，面部结构不扭曲变形。` 光色配合情绪（冷蓝灰压悲伤、暖金衬释然、硬光高对比给愤怒/恐惧）。
5. **过自检清单**，缺项补上再交付。

## 自检清单

- [ ] 每阶段标题是「情绪名+物理动作」双标签
- [ ] 压制篇幅 ≥ 释放篇幅；混合微表情（裂缝）先于崩溃，且被主动收敛
- [ ] 失守有物理因果链（重力/眨眼/呼吸触发），无「突然爆发」
- [ ] 肌肉/解剖词 ≥ 5 处；抽象情绪词 ≈ 0（只允许出现在阶段标签里）
- [ ] 每个动作带幅度副词；≥ 1 处不对称细节
- [ ] 有声音设计（吞咽/鼻腔湿润声/哽咽/呼吸声——有声视频模型必写）
- [ ] 有反表演指令（没有戏剧感/表演感）
- [ ] 技术尾巴含防崩指令（面部结构不扭曲变形）

## 产线注意

- 单条生成普遍 5-10s，放不下完整六阶段（≈20-30s）：**按阶段拆条生成再剪**（建议 1+2 / 3+4 / 5+6 三条），或用三阶段压缩版。
- 「目光直视镜头」是原 prompt 的主动选择（亲密、对峙感）；要纪实感改成「避开镜头/看向画外某处」。
- 出片后若面部表情崩坏/夸张：优先回去**降幅度副词、加解剖词**，而不是重写。
