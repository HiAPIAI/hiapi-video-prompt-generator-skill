# 情绪特写 prompt 模板

复制后按 `[ ]` 填空。阶段可删减（最短三段版：压制→裂缝→溢出），但**顺序不变**。填完过一遍 SKILL.md 的自检清单。

```
【第1阶段：承接/消化——[心理标签，如：不愿承认的事落定了]】
[人物]，[身体先行动作：微微低头/下颌轻收]，[视线：直视镜头却焦距涣散]，[带内心戏的微动作：偶尔极轻点头，像在无声说服自己接受……]，[生理细节：喉咙轻轻滚动，一次克制的吞咽]，[未完成的动作：嘴唇微微分开一缝，停顿后缓缓合拢，什么都没说出来]。

【第2阶段：压制——[定性，如：把情绪封死在皮肤之下]】
[肌群总动员 3-4 块：嘴唇用力抿紧，眉头轻皱，眼轮匝肌轻轻收缩双眼微微眯起，眉间纹加深，嘴角向下压]，整张脸开始绷紧，呼吸变得极浅。[第一波泄漏被压回：下眼睑泪水线隐约积聚，密集眨眼试图压制，眼角已隐隐泛红]。

【第3阶段：裂缝——[2-3 秒的混合微表情]】
沉默中，[心理节点动作：他极轻地点了一下头，像在心里确认了某件事，认了]。随后脸上出现一个极其复杂而短暂的微表情——[A 情绪部位：眉头依然轻轻皱着，带着悲伤与后悔]，但[B 情绪部位：嘴角却极其细微地向上提拉了一点]，不是真正的笑，[意图排比：像是释怀，像是自嘲，像是对某段往事最后一次温柔的承认]。这个表情只持续两三秒，转瞬即逝。随后他像是意识到了什么，试图收敛这个表情，[收敛动作：嘴角重新被抿平，眉头再次轻轻皱紧]，像是不愿让任何人看见刚才那一刻的自己。

【第4阶段：自救失败——[有物理动机的动作反而触发失守]】
他缓缓仰起头，[物理动机：本能地试图借助重力将积聚的泪意逼回眼眶]，[短暂强撑的平静，像是以为这个动作能救他]。但没有。[失守因果链：泪水在仰起的角度下无处可退，随着一次无法控制的细微眨眼，右眼眼角泪水顺着重力沿眼尾向鬓角方向缓缓溢出，物理自然，不悬挂。左眼稍晚，同样在下一次眨眼后溢出]。

【第5阶段：溢出——[放弃封堵，安静地流]】
他缓缓将头低回正面，重新面对镜头。两道泪痕已在脸上，侧光下清晰反光。[放弃用力的部位：眉毛内端轻轻向下沉，是肌肉放弃用力后自然垂落的哀戚弧度]。[抵抗结束的标志：眼睛没有再试图眨动驱散，只是静静地直视前方]。泪水沿脸颊缓缓流淌，细而安静。

【第6阶段：接管——[身体越过意志，完整释放]】
[失守振荡：嘴角抵住的力道开始松动，下唇出现轻微的、不受控制的细碎颤抖，被他咬住，松开，再颤，已经压不回去了]。[眉间深深地、疲惫地向下折叠，鼻翼细碎颤动]。[声音事件：一次无法控制的深吸气——带着清晰的鼻腔湿润声，气流在喉咙深处哽住，咬紧牙关强行压下，但已经晚了]。[第一个不由自主的声音：低沉、沙哑、破碎，从喉咙深处挤出——这声音一出，所有剩余的克制在一秒内瓦解]。肩膀开始不规律地细碎颤动，不是整齐的抽泣，是身体已经在哭而本人还在微弱抵抗时的细碎震颤。呼吸彻底碎裂，分段吸气与颤抖呼气，夹带哽咽与吸鼻声。泪水全面漫开。眼睑轻轻合拢，睫毛湿润，头彻底低垂，整个人安静而完整地哭着——没有戏剧感，没有表演感，只有一个人真正承受某种东西时，身体给出的最诚实的回应。

[风格：超写实风格]，[颗粒：轻微胶片颗粒]，[色调：冷蓝灰色调]，[灯光+方向：自然漫射侧光灯打亮右脸]，背景简洁，画面稳定，[画质：4K高清]，面部结构不扭曲变形。
```

## 填空前先定三件事

- 情绪对：____ × ____（核心情绪 × 对立情绪，没有对立情绪就没有裂缝）
- 压抑动机：____（为什么必须忍——决定 2-4 阶段的形态）
- 失守通道：泪 / 笑 / 吼 / 颤 / 声音劈了（换情绪就是换这个通道）

## 时长适配

- 完整六阶段 ≈ 20-30s：单条生成放不下就拆 1+2 / 3+4 / 5+6 三条再剪
- 三段压缩版（≈8-10s 单条）：压制 → 裂缝 → 溢出
- 每个【第N阶段】标签在投喂模型时可保留——它同时是节奏指令和镜头分段提示
